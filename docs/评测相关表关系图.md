# 评测相关表关系图

本文档说明知识库评测相关表之间的关联关系，重点覆盖 `dataset / query / run / result`，以及它们与 `documents / chunks` 的连接方式。

## 表关系总览

```text
kb_eval_datasets
  dataset_id (PK)
      |
      | 1:N
      v
kb_eval_queries
  query_id (PK)
  dataset_id ---------> kb_eval_datasets.dataset_id
  doc_id -------------> kb_documents.doc_id
  target_chunk_id ----> kb_chunks.chunk_id
      |
      | 1:N
      v
kb_eval_results
  result_id (PK)
  query_id -----------> kb_eval_queries.query_id
  eval_run_id --------> kb_eval_runs.eval_run_id

kb_eval_runs
  eval_run_id (PK)
  dataset_id ---------> kb_eval_datasets.dataset_id

kb_documents
  doc_id (PK)
      |
      | 1:N
      v
kb_chunks
  chunk_id (PK)
  doc_id -------------> kb_documents.doc_id
```

## 关键关联

- `kb_eval_queries.dataset_id` -> `kb_eval_datasets.dataset_id`
- `kb_eval_queries.doc_id` -> `kb_documents.doc_id`
- `kb_eval_queries.target_chunk_id` -> `kb_chunks.chunk_id`
- `kb_eval_runs.dataset_id` -> `kb_eval_datasets.dataset_id`
- `kb_eval_results.query_id` -> `kb_eval_queries.query_id`
- `kb_eval_results.eval_run_id` -> `kb_eval_runs.eval_run_id`

## 关系含义

- `kb_eval_datasets` 表示一个评测集，例如某个 source 上生成的一批 query。
- `kb_eval_queries` 表示评测集里的单条 query。
- `doc_id` 指向这条 query 对应的目标文档。
- `target_chunk_id` 指向这条 query 的 gold chunk，也就是评测时希望命中的目标 chunk。
- `kb_eval_runs` 表示一次评测运行，比如 `bm25`、`vector`、`hybrid` 中的某一种。
- `kb_eval_results` 表示某次评测运行下，每条 query 的命中结果和指标结果。

## 常见查询路径

### 1. 从 query 找目标 chunk

```text
kb_eval_queries.target_chunk_id
  -> kb_chunks.chunk_id
```

### 2. 从 query 找目标文档

```text
kb_eval_queries.doc_id
  -> kb_documents.doc_id
```

### 3. 从 dataset 找全部 query

```text
kb_eval_datasets.dataset_id
  -> kb_eval_queries.dataset_id
```

### 4. 从 run 找全部结果

```text
kb_eval_runs.eval_run_id
  -> kb_eval_results.eval_run_id
```

## 一个具体例子

如果某条 query 记录长这样：

```text
query_id = kb_eval_query_xxx
dataset_id = kb_eval_dataset_xxx
doc_id = wikipedia_zh_real_300:106
target_chunk_id = wikipedia_zh_real_300:106:chunk:0000
```

那么它表示：

- 这条 query 属于某个评测集 `kb_eval_dataset_xxx`
- 它对应的目标文档是 `kb_documents.doc_id = wikipedia_zh_real_300:106`
- 它对应的目标 chunk 是 `kb_chunks.chunk_id = wikipedia_zh_real_300:106:chunk:0000`
- 评测时会用这个 `target_chunk_id` 去判断检索结果里是否命中了正确 chunk，以及命中排位是多少
