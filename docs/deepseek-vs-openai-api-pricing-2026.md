## 四、其他关键差异

| 维度 | DeepSeek API | OpenAI API |
|------|-------------|-----------|
| **缓存折扣** | 缓存命中 **-80%** | Prompt Caching 最高 **-90%** |
| **Batch 折扣** | ❌ 无 | ✅ **-50%**（Batch API） |
| **上下文窗口** | 全系 **1M tokens** | Nano/Mini 1M，部分 128K |
| **最大输出** | **384K tokens** | 通常 16K~32K |
| **多语言支持** | 中英文均优 | 英文最优，中文良好 |
| **函数调用** | ✅ 支持 | ✅ 支持 |
| **视觉能力** | ✅ 支持 | ✅ 支持 |
| **价格优势** | **输出端极便宜** | 经济型输入略便宜 |

## 五、选型建议

1. **追求极致性价比** → **DeepSeek v4-flash**：输出价格低至 $0.28/1M，且上下文长达 1M tokens
2. **最低输入成本** → **GPT-4.1 Nano**：输入仅 $0.10/1M，适合超大输入量的场景
3. **批量处理大规模任务** → **GPT-4.1 mini + Batch API**：可享 50% 折扣
4. **需要最高推理能力** → **GPT-5.5 / DeepSeek v4-pro**：两者各有千秋，v4-pro 目前有 75% 折扣
5. **中文场景为主** → **DeepSeek v4-flash**：中文理解能力优秀，价格仅为同级 GPT 模型的 1/2 到 1/5
